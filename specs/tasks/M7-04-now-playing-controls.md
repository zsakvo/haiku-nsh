# 任务 M7-04：正在播放专属控制区

执行者：Codex。审阅者：Claude。遵守 `specs/tasks/README.md`。在主仓库当前工作区上继续，不提交 git。前置：M7-03 已完成。开始前阅读 `nsh-design-guides`（Design thesis、Layout patterns、Interaction states、Motion、Accessibility checklist）和 `src/ui/STANDARDS.md`。

## 背景

用户要求正在播放不再沿用外面的底栏，而是专门设计一套控制区。UI.md §4/§5 已按此更新（审阅者已改）。

## 1. 布局（`native/app/src/now_playing.rs`，新建 `now_playing_controls.rs`）

双栏，左栏是播放主体，右栏是歌词。整体垂直居中，左右栏之间的间距用现有 spacing token。

左栏自上而下，宽度等于封面宽度，封面最大 420，随窗口高度缩小：

1. 封面（保留唱片装饰）。
2. 信息行：标题（大字号，半粗体，单行截断）+ 下一行“艺术家 · 专辑”（次要前景色，艺术家和专辑可以点击，点击后收起正在播放并导航）。行尾放喜欢按钮和“更多”菜单按钮。“更多”菜单的内容：下载、加入歌单、详情、查找歌词，复用现有的右键菜单项。
3. 进度：整宽 seek 条（复用 `seek_bar`，使用 on-dark 配色与较粗的轨道变体）。下方两端分别显示已播放时间和剩余时间（`-m:ss`，等宽数字）。
4. 主控行，居中：播放模式 · 上一首 · 播放/暂停（主按钮，尺寸明显大于其他按钮）· 下一首 · 队列。
5. 辅助行：左边是音量（图标 + 内联滑杆，不用 Popover），右边是桌面歌词、睡眠定时、音效入口（UI.md §4 的播放设置入口），以及歌词显隐切换。

顶部左上角放收起按钮（chevron-down，Esc 同效）。按钮不放在系统红绿灯区域内。

- 隐藏歌词或窗口宽度 < 900 时，右栏隐藏，左栏水平居中。
- 所有颜色来自现有 `dock-on-dark-*` / `now-playing-*` token；缺少的角色先加进 `src/ui/theme/haiku.json`，不写字面量颜色。
- 控件复用 `player_controls.rs` 的 surface_control 等组件；需要的尺寸变体加在那里，不在页面里单独改样式。所有图标按钮都要有无障碍标签和提示。

## 2. 与底栏的衔接（`player_dock.rs`）

- 正在播放打开期间，根部底栏不显示：在覆盖层升起的同时向下滑出并淡出，收起时反向（时长和缓动沿用 M7-02，并遵守 reduce motion）。底栏仍然是根部的同一个实例，不卸载，所以播放状态、弹层等不会丢失。
- 删除底栏中仅为正在播放服务的 on-dark 分支（`open.get()` 时切换颜色的那部分），如果别处没有使用的话。
- 正在播放的覆盖层改为覆盖整个窗口（`bottom: 0`），不再为底栏预留 112px。

## 3. 键盘

在正在播放中：空格 播放/暂停，←/→ 快退/快进 5 秒，⌘←/⌘→ 上一首/下一首，↑/↓ 调音量，Esc 收起。已有的全局快捷键不变，不冲突。
