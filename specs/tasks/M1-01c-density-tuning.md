# 任务 M1-01c：侧栏与顶栏密度微调

执行者：Codex。审阅者：Claude。遵守 `specs/tasks/README.md`。完成后提交一次并停下汇报。

## 用户反馈（看过 M1-01b 的真实窗口）

左侧侧栏太挤；右侧内容区顶栏太高；搜索框 placeholder 字号减小两号、搜索框再拉长一点；设置界面侧栏也太挤。

M1-01b 是把 M1-01 整体收紧，侧栏收过了头、顶栏没收够。只改下面这些，其余保持 M1-01b 的样子。数值先改 `src/ui/STANDARDS.md` 与 theme/共享组件（`--navigation-row-height` 等），不要在页面里单独调。

## 修改

1. **侧栏放松**（主侧栏与设置侧栏共用同一套值，两边必须一致）：
   - 条目最小高 28 → 32pt，条目之间间距 2 → 4pt；
   - 分组之间间距 16 → 24pt，分组标题与其第一个条目间距 8pt；
   - 红绿灯区与第一个分组（主侧栏）/搜索框（设置侧栏）之间多留 8pt；
   - 设置侧栏的搜索框与第一个分类之间间距 12pt。
   - 侧栏宽度保持 200pt，字号不变。
2. **顶栏变矮**：内容面板内的顶栏高度 48 → 40pt（仍以 `titleBar()` 实际高度为下限；若下限高于 40，取下限并在汇报中说明实际值）。图标按钮、搜索入口仍为 28pt，垂直居中。设置面板的标题栏同样改为 40pt。
3. **搜索入口**：placeholder “前往…” 字号 14 → 12pt（`text-xs`），与 ⌘K 提示等大；宽度在当前基础上加约 40pt（写成固定宽度或最小宽度，在 STANDARDS 中记录数值）。设置侧栏的 `SearchField` placeholder 同样改为 12pt。
