# 任务 M1-01b：外壳视觉修订（更紧凑、更多圆角）

执行者：Codex。审阅者：Claude。遵守 `specs/tasks/README.md`。完成后提交一次并停下汇报。

## 用户反馈

M1-01 的外观“大致可以”，但：整体偏松散；圆角太少，看起来呆板；侧栏顶部的 “Haiku” 标题没有意义。

## 要改的内容

先改 `src/ui/STANDARDS.md` 与 `src/ui/theme`，再改组件和外壳，不要在页面里单独调值。

### 1. 密度：整体收紧一档

- 侧栏宽度 220 → 200pt；侧栏条目高度约 28pt（当前约 40pt），图标 16pt，图标与文字间距 8pt，条目之间间距 2pt。
- 分组标题（发现 / 音乐库 / 歌单）字号 12pt、muted 前景，与上一组间距 16pt（当前偏大）。
- 侧栏正文字号 13–14pt（选一个写进 STANDARDS），选中项字重 medium 即可，不要 bold。
- 顶栏高度 56 → 44–48pt（不低于 `titleBar()` 实际高度）；页面标题 16pt semibold。
- 页面与顶栏的水平边距 24 → 20pt。
- 删除侧栏底部“下载”上方那条分隔线，改用分组间距表达；“下载”仍放在底部。

### 2. 圆角：更柔和、层级更明确

- `radius`（普通控件）6 → 8pt；`radius-inset` 4 → 6pt；`radius-surface`（弹出层、覆盖层卡片）12 → 14pt。新增 `radius-panel`（约 10pt），用于设置中的选项卡片、分组容器。
- 侧栏选中项、hover 项使用 `radius`，并与侧栏边缘保留 8pt 内缩（四角都是圆的，不贴边）。
- 顶栏的搜索入口改为胶囊或 `radius` 圆角，高度与顶栏图标按钮一致（28pt）。
- **主内容区作为一块圆角面板**：侧栏为底色，内容区是一块带 `radius-panel` 圆角、四周留 8pt 间距（左侧与侧栏之间、顶部、右侧、底部）的面板，背景为 `background`，侧栏为 `sidebar`。顶栏放在这块面板内部。注意底部 96pt 将来留给 PlayerDock，本任务面板只需四周留白，不用预留。
- 设置覆盖层右侧的内容区同样处理；“外观模式”三个选项、品牌色网格都用 `radius-panel` 卡片承载。
- 命令面板保持 `radius-surface`，列表选中项使用 `radius`，与面板内边距形成同心圆角（内半径 ≈ 外半径 − 内边距）。

### 3. 侧栏顶部

- 删除 “Haiku” 文字标题。红绿灯区域保持可拖动，红绿灯下方直接是第一个分组；红绿灯区高度与顶栏一致，使第一个分组和内容面板顶部视觉对齐。
- 设置覆盖层左侧顶部的 “设置” 标题同样删除（右侧已有分类标题），搜索框直接在红绿灯区下方。

### 4. 上一轮审阅发现的问题

- 设置分类除“外观”外都用同一个齿轮图标：为每个分类选一个语义合适的 iconoir 图标（账户、外观、播放、歌词、下载、存储、来源、插件、同步、快捷键、其他、开发者），只复制用到的 SVG。
- 品牌色按钮宽度不一：改为等宽网格，每格为色块 + 名称，选中用 ring + 勾，而不是改变按钮宽度。
- 深色模式下空状态插画中的白色块刺眼：插画中原本的浅色/白色改为读取 token（例如 `muted`/`card`），保留插画主色；如果 SVG 不能运行时着色，就按外观模式提供浅色、深色两份插画资源。
