## 0. M4-01 遗留小项

- 库来源浏览：卡片标题与封面左对齐；分组之间留白收紧。库来源侧栏图标不要与“电台”相同。
- 详情页“已加载 N 首 / 加载更多”紧跟在列表末尾，而不是贴在页面底部。

## 1. 搜索页

- 五种实体 tab：曲目、专辑、歌手、歌单、节目；只显示当前来源支持的类型。
- 来源筛选：已启用且有 `search` 能力的来源，默认上次所选；切换来源重新搜索。
- 曲目结果用 `TrackList`（可起播、右键菜单同其他列表）；其他实体用封面网格，点击进 M4-01 详情页（节目若无详情，直接播放或提示，二选一并说明）。
- 加载更多按 SDK 分页；**旧请求结果不得覆盖新查询**（切换关键词、tab、来源时都要成立）。
- 搜索历史：提交时写入，空输入时显示，可删除单项与清空（确认）。
- 加载中、空结果、来源错误（带重试）状态。

## 2. 命令面板（⌘K / 侧栏“前往…”）

- 保留现有导航项；输入关键词后 280ms 防抖，按来源分组，每个来源预览 3 个歌单和 3 首曲目；有“在搜索页查看全部”入口。
- 从面板起播曲目时，队列为该来源完整的曲目搜索结果第一页（不只是 3 首预览），从所选曲目开始。
- 键盘：上下选择、回车执行、Esc 关闭；旧请求同样不能覆盖新输入。

## 3. 导出

- `core.sources.search(source, kind, query, cursor?)`、面板用的多来源预览接口（可在 Rust 内并发、按来源隔离错误）；签名自定并在汇报中列出。

2. `nsh check`、`nsh build`（仅已知例外）、`nsh test`（全绿）。Headless：搜索曲目并起播；切换 tab/来源；慢请求后发起新查询，旧结果不出现；加载更多；搜索历史写入与删除；命令面板防抖预览、从面板起播后队列长度等于完整结果页；Esc 关闭。
3. 真实运行截图（浅色，loopback fixture）到 `.artifacts/m4-02/`：搜索页曲目结果、搜索页专辑网格、空输入时的搜索历史、命令面板预览、库来源浏览（第 0 步）。
