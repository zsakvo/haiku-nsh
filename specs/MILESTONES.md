# 里程碑

每个阶段结束时，在 STATUS.md 中更新相关 F 项的证据。阶段之间的顺序依赖：M0 → M1 → (M2 ∥ M3) → M4 → M5 → M6。

## M0 技术验证与骨架

- 安装 nsh CLI；`nsh init --template mixed` 生成骨架，并调整为 ARCHITECTURE.md §2 的目录结构；建立 native workspace 与各 crate 的空壳。
- 完成 ARCHITECTURE.md §6 的 S1–S8 验证，**S2（QuickJS 双份链接）优先**。
- 迁移参考版 Rust 代码到对应 crate，去掉 RPC 层，原有单元测试全部通过。
- 退出条件：S1–S8 都有结论（通过，或者已确定替代方案）；`nsh check`、`nsh test` 通过；迁移后的测试全部通过。

## M1 外壳、设计系统、本地播放

- 设计标准、主题 token、第一批组件（UI.md §1）。
- 外壳：侧栏、顶栏、导航、命令面板骨架、Cmd+W 隐藏与恢复。
- haiku-playback：队列、模式、编排、会话恢复、睡眠定时；haiku-audio 进程内接入。
- 本地曲库：扫描、列表（TrackList）、标签读取、编辑与覆盖。
- PlayerDock（NSH 绘制）、SeekBar、正在播放页、歌词（本地文件与 sidecar）、封面配色。
- 音效与响度、媒体缓存。
- macOS：媒体中心、媒体键、后台播放、防息屏（MACOS.md §1）。
- 设置窗口骨架：外观、播放、存储。
- 覆盖：F01（部分）、F06、F07、F08（本地）、F09（媒体中心）、F10（扫描与编辑）、F13（缓存）。

M1 拆成以下任务，按顺序执行（任务说明在 `specs/tasks/`）：

| 任务 | 内容 | 主要验收 |
|---|---|---|
| M1-01 | 设计系统（标准、token、第一批组件）+ 外壳（标题栏、侧栏、导航、设置覆盖层与命令面板骨架、应用菜单与快捷键）+ 正式接入关闭隐藏；清理 M0 spike | Headless：导航、历史、覆盖层；浅色/深色截图 |
| M1-02 | haiku-playback：队列、模式、编排、会话恢复、睡眠定时；`Core`/`player` 导出与 CoreBridge（事件 → signal，播放时钟） | Rust 单元测试为主（假音频后端） |
| M1-03 | 本地曲库：扫描根、扫描、索引、覆盖；`TrackList` Rust 组件；本地曲库页（歌曲/专辑/艺术家、多选、右键菜单） | Headless 与真实目录扫描 |
| M1-04 | PlayerDock、SeekBar、正在播放覆盖层、本地歌词（LyricsView/KaraokeLine）、封面配色与预热 | Headless 拖动 seek 规则、歌词跟随；截图 |
| M1-05 | 音效与响度、媒体缓存接线；设置覆盖层的外观/播放/存储分组；媒体中心、媒体键、防息屏正式接入 | 设置持久化、真实播放回归 |

## M2 插件 SDK 与宿主

- haiku-jsrt：完成 PLUGIN_SDK.md §8 的 R1–R12（M0 只做最小子集）。
- haiku-plugins：`haiku` SDK 运行时、包与实例、安装事务、描述符、SourceApi、认证流程（五种方式）、自动刷新。
- `sdk/haiku.d.ts`、三种模板、`haiku-plugin` CLI、契约测试套件。
- 用 v2 重写 subsonic、feiniu、qq-scraper、kugou-scraper、qq-music，全部通过契约测试。
- 设置中的来源、插件、开发者调试面板。
- 编写指南 `sdk/GUIDE.md`。
- 覆盖：F02、F03。
