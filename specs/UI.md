# 界面（F01 F04 F05 F08 F16）

实现任何屏幕前，必须先读 NSH Design Guides（skill `nsh-design-guides`）和 Coding Guides。本文只记录本应用的设计决定。

## 1. 设计系统（M1 第一项工作）

### 1.1 设计标准（`src/ui/STANDARDS.md`，随代码维护）

- 目标：macOS 桌面，指针加键盘；默认密度 standard，曲目列表、表格、工具栏使用 compact。
- 字体：界面使用系统字体（PingFang SC），歌词字体单独设置（D8：只能选择系统字体）。
- 图标：只用一套图标库（沿用参考版的 iconoir，资源随应用打包）。
- 间距、字号、圆角都只使用设计规范中的刻度；控件尺寸有 sm/md/lg 三档。

### 1.2 主题 token（`src/ui/theme`，同时提供给 Rust 组件的 `theme()`）

- 标准角色：background、foreground、card、popover、sidebar、muted、primary、secondary、accent、destructive、border、input、ring，以及各自的 foreground，每个都有浅色和深色值。
- 应用补充的角色：`success`、`warning`、`progress-played`、`progress-buffered`、`dock-surface`、`lyric-active`、`lyric-inactive`、`now-playing-*`。
- 主题：浅色 / 深色 / 跟随系统；品牌色可选。
- **封面配色**属于数据颜色：`haiku-palette` 用 Celebi 量化加 Material Score 选出源色，生成 HCT tones `[30,50,70,85,95]`。正在播放页通过运行时覆盖 `now-playing-*` 和 `lyric-*` token 来使用这些颜色，组件代码中仍然只引用 token。正在播放页始终使用深色角色；没有封面时回退到主题强调色。

### 1.3 组件库（`src/ui/`，包装 `nsh/base`）

按功能需要逐步建设，每个组件都具备完整的交互状态（hover、pressed、focus、selected、disabled、loading）：

Button、IconButton（带 tooltip 和无障碍名称）、Input、SearchField、Select、Switch、Checkbox、Slider、Tabs/ToggleGroup、Menu/ContextMenu、Popover、Dialog、Sheet、Toast、Badge、EmptyState（插画）、ErrorState（带重试和展开详情）、Skeleton、Card（封面卡片）、Shelf（横向货架）、SectionHeader、SettingsRow。

Rust 组件（TrackList、SeekBar、LyricsView、PlayerDock、Artwork）使用同一套 token。

### 1.4 交互约定

- 不使用 hover 工具栏。行级操作放在右键菜单（ContextMenu）和行尾的“更多”菜单按钮中；常用操作（播放）通过双击或回车触发。
- 每个页面都必须有加载、空、失败（带重试）、未登录四种状态。
- 键盘：Cmd+K 打开命令面板；空格切换播放（文本输入时不触发）；Cmd+W 隐藏窗口；Cmd+Q 退出；Cmd+[ 和 Cmd+] 后退与前进；Cmd+, 打开设置；应用菜单与快捷键保持一致。

## 2. 外壳与导航（F01）

```
┌──────────┬──────────────────────────────────────────┐
│ 侧栏      │ 顶栏：后退/前进 · 页面标题 · 来源选择 · 搜索 │
│ 推荐      ├──────────────────────────────────────────┤
│ 分类      │                                          │
│ 电台      │              页面内容                      │
│ 搜索      │                                          │
│ ─────    │                                          │
│ 本地曲库   │                                          │
│ 喜欢      │                                          │
│ 历史      │                                          │
│ 统计      │                                          │
│ ─────    │                                          │
│ 歌单…     │                                          │
│ ─────    │                                          │
│ 下载      │                                          │
├──────────┴──────────────────────────────────────────┤
│ PlayerDock（应用根部唯一实例，左右和底部各留 24pt）      │
└─────────────────────────────────────────────────────┘
```

- 自绘标题栏（`nsh/desktop` titleBar），保留拖动区域。
- **当前实际布局（以 `b364b75` 为准，覆盖上图）**：后退/前进与“前往… ⌘K”搜索入口放在侧栏红绿灯下方；下载与设置图标固定在侧栏底部；内容面板顶栏只保留拖动区域（设置覆盖层保留关闭按钮）。侧栏与设置侧栏共用 `sidebar-icon/text/hint` token。
- 导航历史最多 100 条，新的导航会截断前进历史；页面状态（查询、tab、来源、滚动位置）在离开后保留。
- 路由参数使用宿主编码的 `EntityRef`，往返无损（来源 id 可能包含 `#`，曲目 id 可能包含 URL 字符）。
- 来源/插件管理、“我的”、账号、日志、通知都放在设置窗口或顶栏菜单中，不占用侧栏；侧栏底部预留 96pt，避免被底栏遮挡。
- 桌面端不强制登录。

## 3. 页面清单

| 页面 | 要点 | 依赖的 Rust 服务 |
|---|---|---|
| 推荐 | 当前所选来源的首页货架（参考版只显示所选来源，不聚合）；缓存优先展示；刷新；按来源记录错误与重试 | sources.home |
| 分类 | tag 墙 → 分类歌单，支持排序与分页 | sources.categories |
| 电台 | 频道列表与私人 FM，持续续歌 | sources.radio、player |
| 搜索 | 五种实体的 tab、来源筛选、搜索历史、加载更多；旧请求结果不覆盖新查询 | sources.search、history |
| 详情 | 歌单、专辑、歌手、榜单、节目通用详情页：头部信息 + TrackList；收藏和取消收藏远端歌单 | sources、collections |
| 库来源浏览 | 按插件描述符中的 cards 渲染 | sources.library |
| 本地曲库 | 歌曲/专辑/艺术家、多选、批量编辑、刮削审阅 | library |
| 喜欢 / 用户歌单 | 列表/网格、重排、批量管理 | collections |
| 历史 | 曲目历史与歌单历史两个 tab | history |
| 统计 | 范围切换、计数、排行、小时分布、热图、里程碑 | stats |
| 下载 | 状态筛选、批量操作、目录与选项 | downloads |
| 正在播放 | 见 §4 | player、lyrics |
| 命令面板 | 280ms 防抖；每个来源预览 3 个歌单和 3 首曲目；从这里起播时使用完整的搜索结果作为队列 | sources.search |

所有歌曲列表都使用 `TrackList`（Rust 虚拟列表），行显示**有效元数据**（应用了用户覆盖），右键菜单提供：播放、下一首播放、加入队列、喜欢、加入歌单、下载、详情/编辑。

## 4. 正在播放（F08、F09）

- 点击底栏封面后，从底部升起一个覆盖整个窗口的层（覆盖侧栏和顶栏）；收起动画结束后恢复原页面；不增加导航历史；底栏始终是根部同一个实例，展开和收起都不会卸载。
- 双栏布局：左侧居中的大封面，带唱片装饰；右侧歌曲信息与 `LyricsView`。
- 背景：封面配色（palette index 3）向黑色压暗 50%，叠加顶部 50%、底部 70% 的黑色渐变；配色在后台计算，切歌时忽略过期结果。
- 封面和配色预热：当前曲和下一首的 1600 档封面带 headers 下载到图片缓存并预先计算配色，保证切歌首帧就显示正确的大图和背景。
- 可选防息屏：只在正在播放页可见时生效。
- 播放设置入口：桌面歌词、睡眠定时、音效。

## 5. 底栏 PlayerDock

- 内容：封面、标题/艺术家、上一首/播放/下一首、进度（已播放与缓冲是两个独立图层）、喜欢、播放模式、音量（Popover）、队列（Popover）、歌词按钮。
- 视觉：M1 使用 NSH 绘制的半透明表面；M6 替换为原生 NSVisualEffectView 玻璃效果（MACOS.md §5）。普通页面使用中性灰阶，只有中间的播放按钮使用强调色；正在播放页使用封面色（已播放 tone 15、缓冲 tone 38）。前景色按对比度选择。
- 拖动 seek 的规则见 PLAYBACK.md §6.3。

## 6. 设置窗口（F16）

- 主窗口内的全窗口覆盖层（D18；NSH 0.4.0 不支持第二个窗口）。Cmd+, 或顶栏/命令面板打开，Esc 或关闭按钮收起；打开时保留原页面状态，底栏 PlayerDock 继续显示并可操作；不增加导航历史。
- 左侧为分类导航与搜索，右侧为分组设置。分类：账户、外观、播放、歌词、下载、存储、来源、插件、同步、快捷键、其他、开发者（插件调试面板）。
- 来源：账号行（来源名、登录用户或“未登录”、登录/登出），“添加新来源”打开登录对话框，按描述符的认证方式渲染（二维码、web、短信、表单、cookie）。
- 插件：每个包一行（logo、名称/版本/作者、启用开关）；点击打开详情 Popover（能力、实例、删除需要确认）；标题栏的“导入”菜单提供 ZIP、目录、单个 .ts 文件、HTTPS URL 四种方式。
- 其他：备份导出与导入、日志、关于。

## 7. 测试

- 每个页面都有 Headless 测试：入口可以到达，以及加载、空、失败、重试四种状态（使用假的 SourceApi）。
- 导航：EntityRef 往返、历史截断、页面状态保留。
- 真实窗口截图检查：中文排版、长列表、窗口缩放、浅色与深色主题、较大的文字尺寸。
