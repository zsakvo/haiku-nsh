# Haiku 设计标准

## 产品与平台
- macOS 14+ 桌面优先，指针与键盘并重。保留红绿灯、窗口拖动、原生菜单与系统快捷键。
- 安静、精确，以音乐内容为中心；不用装饰性卡片、渐变、徽章和虚构数据填充空白。
- 当前没有内容的页面说明交付阶段，不提供无效操作，不伪装加载。

## 密度与几何
- 默认 standard；顶栏、侧栏、菜单使用 compact。一个局部区域采用统一密度。
- 侧栏固定 200pt；主内容与设置顶栏期望 40pt，以 titleBar() 实际高度为下限；几何值统一由 theme 与 Chrome 组件提供。
- 主侧栏顶部为 40pt 红绿灯拖动行：按 titleBar().left 预留原生窗口按钮区；其后留 8pt 再接搜索入口。
- 主内容顶栏从左至右为后退、前进、刷新；macOS 胶囊距内容面板顶部 12pt、左侧 24pt，按钮间距 5pt，圆形点击区域 28pt。前进/后退图标画布 20pt，刷新图标画布 12pt，以补偿 SVG 图形占比差异，使可见图形高度接近；尺寸由 navigation 系列 token 和 compact-control-height 提供。
- 主侧栏搜索入口与设置分类搜索共享顶部位置，距首组/分类 12pt；主侧栏底部为设置条目，与上方侧栏条目样式及左右对齐一致，距底边 16pt。
- 页面与顶栏共享左 24pt、右 48pt 水平边距，由 content-inset-left/content-inset-right 提供；两种侧栏共用分组间距 24pt、导航条目间距 4pt；分组标题与首条目间距 8pt（标题底距 4pt 加行间距 4pt），设置搜索框与首分类间距 12pt；控件间距 8pt。
- 间距刻度：2、4、8、12、16、20、24、32、48pt；用 Tailwind 刻度或共享 token，不在页面发明偏移值。
- 侧栏条目最小高 32pt，图标 15pt、正文 13pt、图文间距 8pt，左右距侧栏边缘 8pt；鼠标悬浮不添加背景色，选中只用 medium 字重。
- 表单控件贴近 macOS 标准尺寸，轻量精致：按钮 md 最小高 24pt、文字 13pt（control-text-size），sm 最小高 20pt、文字 12pt（control-text-sm-size），圆角 radius-inset 6pt；secondary 为 card 底 + 细边框 + shadow-sm。开关轨道 32×18pt、滑块 14pt；分段控件总高约 24pt、内缩 2pt；输入框最小高 24pt、文字 13pt；滑杆点击区 16pt、滑块 12pt。图标按钮与顶栏搜索入口仍为 28pt，图标 16/20pt。
- 下拉选择统一用 SettingSelect：macOS 弹出系统原生 NSMenu（当前项打勾），其余平台使用自绘 Select。设置行内（inline）为无边框弹出按钮，值使用 setting-value-size 12pt、muted 前景，比 13pt 行标题低一级以体现主次。
- 侧栏搜索入口最小宽 176pt、填满侧栏内宽；“前往…”与快捷键提示、设置搜索 placeholder 同为 11pt；设置搜索输入正文为 13pt。
- 内容顶栏不显示页面标题；macOS 固定顶栏使用整宽模糊背景与底部细分隔线，导航胶囊可拖动；其他桌面平台保留至少 48pt 的导航行。设置顶栏保留 40pt 拖动区和右侧关闭按钮。
- 主内容导航组依次为后退、前进、刷新、当前页面来源 chip；推荐页不再重复提供“刷新推荐”按钮。
- 推荐页不显示独立“推荐”标题。内容区顶栏依次为后退、刷新、搜索入口（命令面板），来源选择位于行尾，采用全圆角模糊玻璃胶囊（原生实时模糊 + 半透明品牌色调洗色 source-chip-accent-tint + 品牌色细边框 source-chip-accent-border，图标与名称用 source-chip-foreground；后退、刷新、搜索用更淡的品牌色调玻璃 source-chip-tint/source-chip-border（「素」主题为中性），高 source-chip-height 26pt（低于其他 32pt 顶栏控件，垂直居中），图标尺寸 source-icon-size 16pt、名称字号 source-label-size 11.2pt、图文间距 6pt，左内边距 6pt、右内边距 10pt，紧凑包裹内容）；macOS 点击弹出原生系统菜单切换来源，其余平台使用自绘制下拉选择；不提供前进按钮（前进仅保留快捷键与菜单）。顶栏高 navigation-bar-height 64pt（与底部播放栏同高），控件统一 navigation-control-height 32pt、间距 10pt，左右内边距对称均为 content-inset-left 24pt，主内容从其下方 navigation-content-gap 12pt 开始。顶栏与内容同色、无色差，静止时没有分隔线；推荐与歌单详情的留白随列表滚动，仅当内容滚入顶栏下方时才显示一条浅色细分隔线。macOS 顶栏使用原生实时背景模糊叠加与内容背景同色的半透明洗色，滚入的内容隐约透出。
- 发现和搜索页面的来源选择放在导航组末尾：圆形胶囊 chip，文字 12pt、插件图标 14pt，使用原生 Select 行为下拉切换；页面内不重复显示来源标签和选择框。
- 推荐页歌曲货架横向分页，每屏两列、每列三首；单行 84pt、封面 52pt，分别由 home-track-row-height/home-track-cover-size 定义。歌曲显示封面、歌名、喜欢状态、来源实际提供的音质及艺术家；悬浮或键盘聚焦显示播放、下载、喜欢和更多操作。整块悬浮时显示两侧翻页箭头，边界禁用；同时保留触控板横向滚动与键盘操作。其他页面继续使用表格歌曲列表。
- 首页连续推荐流按来源顺序混排歌曲、歌单和专辑，使用虚拟化封面网格；列数随内容宽度变化，最小列宽复用 listening-cover-size，列间距 16pt。网络分页不产生换行或重复标题，最后一行保留空槽；歌曲卡片显示艺术家，点击播放，集合卡片打开详情。近底部自动续载，失败在流末尾重试并保留已加载内容。
- 推荐页分区标题、歌曲封面与其他卡片共用左 24pt、右 48pt 的水平对齐线，不叠加卡片内缩。歌曲翻页按钮放在两侧页面留白内、高 48pt；左按钮宽 16pt、距面板边缘与内容各 4pt；右按钮宽 20pt、距面板边缘 20pt、距内容 8pt，为纵向滚动条保留独立空间。不占歌曲列宽；悬浮区域包含两侧留白，移向按钮时保持可见。
- 推荐入口使用 150×190pt 竖向封面，对应 2× Retina 屏幕上 300×380 像素（theme 中统一以 rem 定义），圆角 6pt、横向间距 11pt；窄窗口横向滚动。顶部渐暗遮罩承托白色 12pt 标题，右下角 30pt 圆形播放按钮距右边、底边各 6pt，与封面导航各自独立；加载时禁用重复播放，失败就近重试。
- 电台类型的推荐入口（包括 QQ 音乐「猜你喜欢」）没有封面导航或封面按钮语义，只有右下角播放按钮启动电台；歌单、专辑等集合封面仍可打开详情。根据资源类型决定交互，不根据标题判断。
- 歌单详情使用 210pt 方形封面、12pt 圆角，封面区域距内容顶部 64pt，与右侧信息间隔 24pt；“播放全部”和“下载全部”使用全圆角胶囊形按钮。专辑等其他详情保留 134pt 封面。右侧为 20pt 标题、最多两行 13pt 简介、12pt 元信息，以及播放、下载和更多菜单。编辑、删除、筛选、排序与自动下载从更多菜单进入，错误始终可见。
- 详情页由一个虚拟列表统一滚动封面信息、表头、歌曲和分页；行高 58pt，曲目封面 36pt。列为序号、标题/艺人、专辑、喜欢、时长及曲目菜单；标题与专辑按 1.6:1 分配余量，底部保留播放栏避让。几何使用 detail 系列 token，颜色使用现有语义 token。
- 顶部推荐封面默认隐藏播放按钮；悬浮时显示按钮、标题下方最多五首歌名和覆盖整张封面的遮罩，移出恢复。歌名前显示 1. 至 5. 序号，序号与歌名统一使用偏灰白的 cover-muted-foreground。遮罩、曲目预览与按钮使用 300ms 渐入渐出，遵循系统减少动态效果设置；预览不启动播放。
- 发现页听书与歌单/专辑卡片：封面 150×150pt，卡片无额外内边距和鼠标悬浮效果；横向间距与上方推荐共享 recommendation-cover-gap，为 11pt。标题 12pt、使用 muted-foreground，最多一行，尾部省略；保留键盘聚焦轮廓。几何与字号统一由 listening 系列 rem token 提供。
- 控件最小高度与内边距共同约束，不固定文字容器高度。触摸平台另行扩至 44pt。
- 标准窗口 1200×800；内容区可收缩，列表/设置内容各自滚动。
- 首版舒适下限 900×700；更窄窗口优先保留内容和导航，允许设置区域滚动。
- 所有横向滚动区域使用统一的应用滚动条主题隐藏轨道和滑块，替代 macOS 强制显示的原生横向指示器；推荐、听书、专辑、歌单等内容保留横向滚动能力。

## 字体与图标
- 系统 UI 字体（中文使用系统 PingFang SC）；快捷键提示使用系统等宽字体。
- 字号：侧栏分组/提示 11pt、侧栏正文 13pt，分别由 sidebar-hint-size/sidebar-text-size 统一提供；侧栏外为 12pt 元信息、14pt 控件/正文、18pt 分组、20pt 页面标题。
- 发现页面的 Shelf 区块标题为 16pt，保留 semibold 层级。
- 标题少量 semibold，正文 regular；中文不强制大写、不加装饰性字距。
- 仅用 iconoir，一次复制实际使用的 SVG 与许可证。图标通过 Image 的 tintColor 读取 token。
- 图标固定槽位保持列对齐；图标按钮必须有无障碍名称和 tooltip。
- 空态使用带许可证的 unDraw 插画；Image 只能整图 tint，故提供浅/深资源，深色将浅色块映射为主题 card/muted，保留插画主色。

## 主题与颜色
- 唯一颜色定义位于 src/ui/theme；其余 UI 只能消费语义 token。
- 标准角色覆盖背景、前景、卡片、popover、sidebar、muted、primary、secondary、accent、destructive、border、input、ring。
- 应用角色覆盖 success、warning、进度、底栏、歌词和 now-playing；封面数据颜色日后经 token 覆盖进入。
- 品牌色是唯一颜色种子：palette.ts 在 OKLCH 中取其色相，生成整套中性色（背景、侧栏、卡片、muted、边框、输入、文字）——低彩度（浅色 C≈0.01、深色 C≈0.014）带品牌色相的灰，参考 Linear 的 base/accent/contrast 模型与 Radix 的染色灰阶；选中态（selection、sidebar-accent）为品牌色浅染，正在播放/封面等沉浸表面同色相深色。各品牌共用同一亮度结构，对比度一致。不以深浅色专用 class 代替 token。
- 17 种品牌色为等亮度 OKLCH 色票，默认 orange；另有「素」（neutral）：无彩色种子生成纯灰阶，浅色背景为纯白、primary 为墨黑，深色为中性黑，沉浸表面同样去色；primary 浅色取 L 0.58、深色取 L 0.76 并降低彩度。haiku.json 中的浅/深 token 为默认品牌的生成结果，调整 palette.ts 后需重新生成。
- primary-foreground 在饱和中间色上取白、仅浅色填充取黑；主色仅用于默认提交与持久选择。
- 页面内的主要动作（如详情页「播放全部」）用色调按钮：primary-soft 浅品牌色底 + primary-soft-foreground 品牌色文字与图标，不用实心 primary。
- 外观模式与品牌色由 Rust 设置服务原子持久化，TSX 订阅已提交镜像；Rust set_tokens 与 NSH setColorScheme 同步所有消费者。

## 圆角与表面
- radius 8pt：普通控件；radius-inset 6pt：快捷键/嵌套小表面；radius-panel 10pt：内容面板/设置选项卡片；radius-surface 14pt：弹出表面。
- 窗口底色为 sidebar，主内容和设置右侧共用 background 面板，紧贴侧栏及窗口上、右、底边缘，无外边距与圆角。PlayerDock 高 64pt、内部水平 padding 12pt，无圆角，悬浮于主内容区域底部上方（不单独占用布局高度），左右与内容区对齐并贴紧窗口底边；使用实时模糊（header 材质）叠加半透明 dock-surface 洗色与 1pt 顶部细分隔线。滚动内容末尾保留 dock-scroll-clearance 88pt（64pt 底栏高度 + 24pt 留白），防止最底部内容被底栏遮盖。侧栏底部控件距底边 16pt。
- PlayerDock 中央控制区占内宽 40%、最大宽 384pt；两侧区域等分余量，确保上一首、播放/暂停、下一首在卡片内居中。三个控制向下偏移 4pt 靠近进度条；播放/暂停按钮 28pt、实心图标 24pt、无底色；下方进度条两端分别为当前时间和总时长。喜欢按钮紧跟歌名，使用 19pt 点击区域与 13pt 图标；正在播放页保留普通尺寸。右侧仅保留播放模式、音量、队列，统一 26pt 点击区域与 14pt 图标、间距 6pt 并水平居中；播放模式通过 tooltip 与无障碍名称说明当前状态，不在按钮下方显示文字。封面保留正在播放入口。
- 设置的模式卡片等分剩余宽度；品牌色使用等宽自适应网格，固定保留勾槽位，选中用 ring 与勾，不改变几何。
- 命令列表内缩 6pt，与 14pt 外圆角、8pt 选中项圆角形成同心层级。
- 嵌套半径考虑内边距，暴露的圆角不被子背景覆盖；聚焦轮廓必须留有空间。
- 所有 Tooltip/Menu/ContextMenu/Dialog 使用同一 popover、边框、圆角和 shadow-lg。
- 基础区域平面化；分隔线由边界一方绘制。设置覆盖层用实色背景，不应用玻璃。

## 状态与交互
- 正在播放歌词使用系统 UI 字体并隐藏滚动条；歌词行左右内边距 12pt。手动滚动不显示返回按钮，停止滚动后在下一句开始时恢复跟随；点击歌词跳转和自动跟随从实际可见位置以 480ms 平滑移动到中央，手动滚动立即打断动画，遵循减少动态效果设置。底栏和正在播放页的进度条均显示已播放时间与总时长。
- 全局无 hover 视觉效果：作为桌面客户端应用，按钮、选项、菜单项、列表项、卡片与滑块等交互组件不添加鼠标悬浮（hover）变色、背景填充或透明度变化；仅保留 rest、pressed（muted 或主色/透明度变化）、focus-visible、selected/checked 与 disabled 状态。功能性的局部浮层显隐（如推荐封面曲目预览、首页歌曲货架操作显隐、桌面歌词悬浮工具栏）不在此限，但其内部按钮本身同样不添加 hover 样式。
- focus-visible：2pt ring 轮廓；不依赖颜色 alone，保留选中标记/字重。
- selected/checked：selection 填充、明确前景和标记；侧栏不加单侧色条。
- disabled：降低到 35–40% 强度，由基础组件阻止输入；loading 保留原标签并禁用重复提交。
- 异步失败就近说明原因与恢复操作；即时可逆设置以控件状态反馈，不弹成功提示。
- Button 只保留 primary/secondary/ghost/destructive 与 sm/md；primary 用于默认确认。
- 重置、清除、清空等会丢弃用户数据或配置的按钮（包括打开确认框的入口按钮和确认按钮）一律用 destructive 实心样式。
- 所有 Dialog 由 Surfaces 的 Dialog 统一在窗口内水平垂直居中，调用处只给宽度与内边距，不写 self-center/mt-*/m-auto；仅命令面板用 placement="top" 靠上。
- 所有交互包装 nsh/base，不用裸 View 重做按钮、焦点、菜单或 modal 生命周期。
- Esc 关闭最上层；Dialog 负责焦点约束和返回。设置与命令面板互斥，不叠加。
- 后退、前进、刷新、设置与命令面板共享命令函数；原生菜单与应用内提示使用同一快捷键定义。
- Cmd+[ / Cmd+] 导航；Cmd+Shift+R 刷新当前页面（Cmd+R 保留给桌面歌词）；Cmd+K 命令面板；Cmd+, 设置；Cmd+W 隐藏；Cmd+Q 原生退出。
- 裸字母不绑定全局；输入控件保持编辑快捷键。窗口拖动区域不承担其他隐式命令。

## 状态所有权与文案
- TSX 持有路由、最多 100 条历史、页面内状态与覆盖层；外观/播放/存储设置及业务状态由 Rust 持有，TSX 只做订阅镜像。
- 稳定路由和页面身份不使用翻译文本；EntityRef 视为不透明宿主编码，不拆分来源标点。
- 页面保持挂载，离开后保留输入和滚动；设置不改变历史，收起后继续原任务。
- 刷新由当前页面注册能力；本地曲库、专辑、艺术家页面重新扫描，推荐、分类、电台频道、搜索、来源曲库与远程详情重新加载当前资源，统计重新聚合。保留筛选、选择和历史；没有手动刷新能力、缺少必要来源或忙碌时禁用刷新。
- 目的地用名词，操作用动词；打开需要进一步输入的表面用省略号“…”；短标签不加句号。
- 推荐卡片悬浮状态使用 300ms 渐入渐出，歌词定位使用 480ms 平滑滚动；支持 reduced motion，不让动效承担唯一状态信息；不加入声音。

## 验证
- Headless 证明导航、快捷键、状态和关闭契约；真实窗口截图证明布局、裁切与对比度。
- 新组件必须覆盖默认、pressed、focus、selected、disabled（不添加鼠标悬浮 hover 样式）；有异步工作才提供 loading/error。
- 按任务列出的验收执行，不扩展为无边界的设计审计。
